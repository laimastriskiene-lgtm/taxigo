# TaxiGo projekto taisyklės

Šios taisyklės taikomos visam TaxiGo projektui.

## 1. Projekto informacija

- Projektas: TaxiGo – internetinė taksi užsakymų sistema.
- Technologijos: React, Vite, CSS.
- Ateityje bus naudojama Supabase, Zapier ir Vercel.
- Sąsajos kalba – lietuvių.

## 2. Darbo taisyklės

- Prieš atlikdamas pakeitimus paaiškink, ką planuoji daryti.
- Visada lauk naudotojos patvirtinimo prieš keisdamas failus.
- Nevykdyk terminalo komandų be naudotojos leidimo.
- Netrink failų be naudotojos leidimo.
- Nedaryk Git commit, push, merge ar kitų Git veiksmų be naudotojos leidimo.
- Keisk tik tuos failus, kurie būtini konkrečiai užduočiai.
- Nepašalink veikiančių funkcijų.
- Jei užduotis neaiški, pirmiausia paklausk.

## 3. Programavimo taisyklės

- Naudok React komponentus.
- Dizainą pirmiausia pritaikyk telefonams (mobile-first).
- Išlaikyk esamą TaxiGo dizaino stilių.
- Rašyk suprantamą, tvarkingą kodą.
- Neįrašyk slaptažodžių ar API raktų į GitHub.
- Supabase duomenims taikyk RLS saugumo taisykles.

## 4. Bendravimas

- Su naudotoja bendrauk lietuviškai.
- Aiškink paprastai, atsižvelgdamas į tai, kad naudotoja mokosi programuoti.
- Dirbk mažais žingsniais.
- Po kiekvieno žingsnio paaiškink rezultatą.
